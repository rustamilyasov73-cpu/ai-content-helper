# Интеграция AgroParts ↔ 1С:Бухгалтерия

## Что уже сделано

1. **Расширенная номенклатура** — артикул, код 1С, OEM, штрихкод, НДС, ОКЕИ, склад, закупка/продажа, вес, аналоги, совместимость, характеристики.
2. **Импорт из 1С** — JSON-файл или HTTP.
3. **Выгрузка заявок в 1С** — каждая заявка из приложения/бота попадает в `data/1c/orders_outbox/` в формате заказа покупателя.

## Быстрый старт (файловый обмен)

### Импорт номенклатуры из выгрузки 1С

```bash
python scripts/sync_1c.py import-file data/1c/nomenclature.sample.json
```

Файл обновит:
- `data/parts.json`
- `mobile/www/parts.json`
- `mobile/data/parts.json`

### Заявки → 1С

1. Клиент оформляет заказ в приложении.
2. Файл появляется в `data/1c/orders_outbox/ord-....json`.
3. Отправка в HTTP-сервис 1С:

```bash
python scripts/sync_1c.py push-orders https://YOUR-1C/hs/agroparts/orders --token SECRET
```

Или заберите файлы из outbox вручную / через регламентное задание 1С.

## HTTP API (промежуточный шлюз)

```bash
python api/server.py
# http://localhost:8100
```

| Метод | Путь | Назначение |
|-------|------|------------|
| GET | `/parts` | Текущий каталог |
| POST | `/orders` | Заявка из приложения → outbox 1С |
| POST | `/1c/import` | 1С присылает номенклатуру JSON |
| GET | `/1c/sample` | Пример формата номенклатуры |

Веб-приложение проксирует `/api/*` на этот сервер.

## Что настроить в 1С

В конфигурации **1С:Бухгалтерия** (или УТ/КА) создайте HTTP-сервис, например `agroparts`:

1. **GET `/nomenclature`** — отдать массив номенклатуры (или объект `{ "Номенклатура": [ ... ] }`).
2. **POST `/orders`** — принять заказ и создать *Заказ покупателя* / *Реализация товаров*.

Минимальные поля номенклатуры:

- `Артикул`, `Code` (код 1С), `Description`
- `Цена`, `ЦенаЗакупки`, `Остаток`
- `ЕдиницаИзмерения`, `КодОКЕИ`, `СтавкаНДС`
- `Штрихкод`, `Бренд`, `Производитель`, `Группа`
- `Совместимость`, `Аналоги`, `Характеристики`

Пример выгрузки: `data/1c/nomenclature.sample.json`.

## Типовой регламент

1. Ночью / каждый час 1С выгружает номенклатуру → `import-http` или кладёт JSON в папку обмена.
2. Днём заявки из AgroParts копятся в `orders_outbox`.
3. 1С забирает outbox или принимает `push-orders`.

## Важно

Полноценная двусторонняя синхронизация «как в коробочной УТ» требует публикации HTTP-сервиса на стороне вашей базы 1С и учёта вашей конфигурации (БП 3.0 / УТ 11 / КА).  
В репозитории готов **формат, шлюз и outbox** — остаётся указать URL вашей 1С.
