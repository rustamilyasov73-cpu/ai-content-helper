# AgroParts — приложение для телефона

Мобильное приложение каталога запчастей (Expo / React Native).  
Открывается на Android и iPhone через **Expo Go**.

## Что внутри

- каталог с фильтром по категориям и брендам
- поиск по артикулу / названию / бренду
- распознавание бирок по фото (OpenAI Vision)
- корзина с количеством и заявка с телефоном

## Открыть на телефоне

1. Установите [Expo Go](https://expo.dev/go) на телефон.
2. На компьютере:

```bash
cd mobile
npm install
npx expo start
```

3. Отсканируйте QR-код:
   - **Android** — в приложении Expo Go
   - **iPhone** — камерой (откроется Expo Go)

Компьютер и телефон должны быть в одной Wi‑Fi сети.  
Если QR не открывается, в терминале Expo нажмите `s` (switch to tunnel) и снова отсканируйте код.

## Распознавание фото

Во вкладке **Настройки** укажите `OpenAI API Key` (модель с vision, например `gpt-4o-mini`).  
Каталог и корзина работают без ключа.

## Веб-проверка (на компьютере)

```bash
cd mobile
npx expo start --web
```
