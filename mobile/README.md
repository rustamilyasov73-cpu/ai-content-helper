# AgroParts — приложение для телефона

Мобильное приложение каталога запчастей (Expo / React Native).  
Версия **1.2.0** · распознавание бирок — **OpenAI Vision** (`gpt-4o-mini`), не Gemini.

Открывается на Android и iPhone через **Expo Go**.

## Что внутри

- каталог с фильтром по категориям и брендам
- поиск по артикулу / названию / бренду
- распознавание бирок по фото (OpenAI Vision)
- корзина с количеством и заявка с телефоном

## Переустановка / новая версия на телефоне

Если на телефоне старая сборка (или кажется, что стоит Gemini):

1. В Expo Go: откройте проект AgroParts → меню → **Reload** / удалите проект из недавних.
2. На компьютере полностью переустановите зависимости и запустите заново:

```bash
cd mobile
rm -rf node_modules .expo
npm install
npx expo start -c
```

3. Отсканируйте **новый** QR-код в Expo Go.
4. Откройте вкладку **Настройки** — сверху должно быть:  
   `AgroParts 1.2.0 · OpenAI Vision (gpt-4o-mini)`.

## Открыть на телефоне (первый запуск)

1. Установите [Expo Go](https://expo.dev/go) на телефон.
2. На компьютере:

```bash
cd mobile
npm install
npx expo start
```

3. Отсканируйте QR-код:
   - **Android** — в приложении Expo Go
   - **iPhone** — камерой (откроется Expo Go)

Компьютер и телефон должны быть в одной Wi‑Fi сети.  
Если QR не открывается, в терминале Expo нажмите `s` (switch to tunnel) и снова отсканируйте код.

## Распознавание фото

Во вкладке **Настройки** укажите `OpenAI API Key` (ключ с platform.openai.com, начинается с `sk-`).  
Gemini / Google AI не используются. Каталог и корзина работают без ключа.

## Веб-проверка (на компьютере)

```bash
cd mobile
npx expo start --web
# или лёгкая веб-версия:
node scripts/serve-web.js
```
