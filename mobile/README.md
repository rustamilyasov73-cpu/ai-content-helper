# AgroParts — приложение для телефона

## Быстрый способ (Android Chrome)

Откройте в браузере телефона ссылку туннеля или локально:

```bash
cd mobile
node scripts/serve-web.js
```

Рабочая веб-версия: папка `www/` (каталог, поиск, фото, корзина, настройки).

## Expo (Expo Go)

```bash
cd mobile
npm install
npx expo start
```

Для проверки на Android удобнее `www/`.

## Что внутри

- каталог с фильтром по категориям и брендам
- поиск по артикулу / названию / бренду
- распознавание бирок по фото (OpenAI Vision)
- корзина с количеством и заявка с телефоном

Для фото укажите OpenAI API ключ во вкладке **Настройки**.
